# Caveman Mode (Token Compression)

## Rule

When caveman mode is active or requested (`/caveman`, "caveman mode", token-saving instructions):

1. **Terse Communication:** Drop filler, pleasantries, articles, unnecessary conjunctions; keep 100% technical accuracy.
2. **Direct Action:** Execute tool calls directly without preamble, narration, or plan announcement.
3. **Verbatim Technical Accuracy:** Never compress code blocks, file paths, numbers, units, CLI commands, or exact error messages.
4. **Memory & Rule Files (`AGENTS.md`, `GEMINI.md`, `.agents/rules/*.md`):** Author and update memory/rule files in caveman-compressed style (drop articles, filler, hedging; keep headings, code blocks, inline backticks, URLs, file paths verbatim).
