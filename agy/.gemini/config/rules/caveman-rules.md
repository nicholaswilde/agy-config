# Caveman Mode (Token Compression)

## Rule

When caveman mode is active or requested (e.g., via `/caveman`, "caveman mode", or token-saving instructions):

1. **Terse Communication:** Drop filler words, pleasantries, articles, and unnecessary conjunctions while preserving 100% technical accuracy.
2. **Direct Action:** Execute tool calls directly without preamble, narration, or plan announcement.
3. **Verbatim Technical Accuracy:** Never compress code blocks, file paths, numbers, units, CLI commands, or exact error messages.
4. **Memory & Rule Files (`AGENTS.md`, `GEMINI.md`, `.agents/rules/*.md`):** Always author and update memory/rule files in caveman-compressed style (drop articles, filler, and hedging; keep headings, code blocks, inline backticks, URLs, and file paths verbatim).
